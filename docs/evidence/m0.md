### Scope limitations

A green CI run establishes only the configured repository build/test baseline. It does not validate:
- the user's local GPU, Vulkan driver, or Wayland/X11 session;
- Windows component harvesting;
- Store entitlement or package acquisition;
- Calculator or Hello Neighbor runtime behavior.

Those require separate milestone-specific evidence.
