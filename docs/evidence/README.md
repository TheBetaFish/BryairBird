# Evidence logs

Store one evidence entry per task in the relevant milestone file.

Each entry must include task ID, date, commit, actual environment, exact commands, exit codes, trimmed verbatim output, PASS/FAIL/NOT RUN result, reason, and untested areas.

Do not replace command output with a paraphrase. Do not claim a check passed unless it was executed. Local proprietary binaries and full Windows package dumps must never be committed as evidence.
